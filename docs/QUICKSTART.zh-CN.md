# TK Dataset Studio 首次使用

## 下载与启动

到 [GitHub Releases](https://github.com/Ararararararaki/TK-Dataset-Studio/releases/latest) 下载 Windows x64 `.exe` 并双击。单文件包自带独立 Python 运行时，无需 ComfyUI、Node.js 或单独安装 Python。不包含图片、模型权重或账号。每个人的界面、数据集和设置保存在自己的 Windows 用户数据目录。

## 选择处理方式

- **仅 WD14**：在「设置与模型 → WD14 模型」登记已有 ONNX + 匹配 CSV，或下载内置模型；使用「Danbooru 标签」预设。默认 CPU 推理，不需要 LLM 或 DSH。
- **WD14 + LLM**：选择自然语言、标签 + 描述或 MOSS Layout 预设。WD14 提供候选，模型直接看图并生成最终文本。
- **仅 LLM 看图**：在右侧处理方式中选择，无需 WD14 模型。所选服务必须支持图片输入。

## 连接模型

主界面的两个通道按钮可直接切换，选中项有描边，开始按钮旁显示当前通道。运行中的批次使用启动时的配置，切换影响下一批。

**API 直连**：点击「连接」，选择读取 DSH 已保存的静态连接，或手动填写 OpenAI 兼容 Base URL、模型 ID 和自己的 Key；检测连接并选择模型。图片直接传给模型，不创建 DSH 会话。此通道不执行 DSH 会话插件。

**DSH Agent**：需先安装并启动 DSH、配置可看图的模型和公开 Relay 接口，然后在本软件检测连接、选择 DSH 已注册的工作区。此模式会创建独立会话，由 DSH 管理原生工具、插件和权限。安装了某个插件不代表每次请求都会执行，本软件不保证特定插件生效。

辅助 Skill 会从当前账号的 `.dsh/skills`、`.codex/skills` 中发现与图像、标签、角色、MOSS 有关的 `SKILL.md`，可在右侧多选。读取本地 Skill 作为指导参考与执行 DSH 插件是两种不同能力。

## 导入与打标

1. 拖入图片文件夹，或点击「导入图片文件夹」。原图不会移动。
2. 选择预设、模型和指导词。可另存自己的预设；复核可选，开启后会多一次模型请求。
3. 勾选图片后只处理所选；未选择时处理当前数据集。空白处可拖动框选，Ctrl + 滚轮调整图片显示大小。
4. 成功后自动写同名 UTF-8 `.txt`，图片与标注同时显示。已有 TXT 默认跳过，显式覆盖会先备份。

自然语言预设拒绝明显的纯标签输出；失败、拒绝或截断不写入 TXT。API 错误不自动重复计费请求，连续三张失败会暂停。不要将“格式通过”理解为人物身份、细节和构图全部正确；训练前仍可直接编辑和检查。

## 数据与退出

关闭窗口会保存编辑并释放本软件的后端、WD14 进程和 Agent 端口。用户自己启动的 DSH / ComfyUI 保持原样。数据默认位于 `%APPDATA%/TK Dataset Studio`，备份时先关闭应用，再复制该目录；原图和同名 TXT 另行备份。

外网下载和 API 默认使用 Clash `http://127.0.0.1:7890`，可在「文件与输出」调整代理。代理失败不会静默改成直连。回环网关直连。
